pub fn unique_data_dir() -> TempDir
Expand description

Return a fresh, process-unique temporary directory to use as an isolated persistence/data directory in a test that builds its own config.

Analogous to unique_wal_dir; see its docs for the CWD-relative-default cross-pollution rationale (Issue #3500). Provided as a companion so a test that isolates both a wal_dir and a data_dir reads clearly at the call site. Like unique_wal_dir, each call returns a DISTINCT directory that must be kept in scope for the lifetime of the database.

§Panics

Panics if the OS temporary directory cannot be created.
