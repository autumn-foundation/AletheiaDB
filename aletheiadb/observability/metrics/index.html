Source

Metrics contract for AletheiaDB.

Metric names are stable public API. The built-in METRICS value keeps a small atomic mirror for tests and local diagnostics; production export is handled by an installed MetricsRecorder such as metrics_rs_adapter::MetricsRsRecorder.
