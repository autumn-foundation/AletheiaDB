Provenance hash chain integration: capture, rebuild, and verification API (Issue #3351). Provenance hash chain integration on AletheiaDB (Issue #3351).

This module wires the opt-in tamper-evident chain into the database:

  • capturing the version refs a committed transaction produced (hot path),
  • rebuilding the unsealed tail from replayed history at startup, and
  • the public verification / anchor-export API.

When the chain is disabled (the default), none of this runs and the verify API returns a clear “not enabled” error, so behavior is byte-identical to a database without the feature.
