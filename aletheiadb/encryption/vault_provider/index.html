HashiCorp Vault key provider (Issue #3587), gated behind encryption-vault.

Reads the Master Encryption Key (MEK) from a Vault KV v2 secret. Because the KeyProvider trait is synchronous, this provider uses reqwest::blocking – no async runtime bridge is required.

§Model

get_mek() issues GET {address}/v1/{mount}/data/{path} with an X-Vault-Token header, parses the JSON body, and reads data.data.<key_field>. The value may be either 64 hex characters or a base64-encoded 32-byte key.

§Security

The Vault token is a bearer secret: it is held in a zeroizing wrapper, is redacted by Debug, and is never placed in any error Display/Debug output.
