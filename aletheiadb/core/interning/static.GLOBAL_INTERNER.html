Global string interner for sharing common strings across the database.

This static provides a single, thread-safe string interner that can be used throughout the application to deduplicate common strings like labels and property keys.

The global interner is automatically warmed at initialization with common strings such as “name”, “id”, “type”, “label”, “created_at”, “updated_at”, “valid_from”, “valid_to”, “tx_from”, and “tx_to” to provide predictable startup performance.

§Configuration

The maximum capacity can be configured via the ALETHEIADB_MAX_INTERNED_STRINGS environment variable. If not set, defaults to 10,000,000. Opening a database further reconfigures it from persistence.max_interned_strings.
