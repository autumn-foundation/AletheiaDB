pub fn is_reserved_property_key(key: &str) -> bool

Whether a property key is engine-reserved (owned by the namespace ride-along or the crypto-shred lane) and therefore forbidden on user writes and elided from user-facing views.

This is the single source of truth for the reserved-prefix policy; wire it into every place that either validates an incoming user property map or renders one to a user-facing payload.
