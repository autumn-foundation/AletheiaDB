Version management and metadata.

This module implements the version chain structures that enable time-traveling queries. Each node and edge can have multiple versions over time, linked together in a chain ordered by transaction time.

It includes:

  • VersionMetadata: Metadata about version creation (Snapshot Isolation).
  • NodeVersion / EdgeVersion: The version structures.
  • VersionData: Payload (Anchor or Delta).
