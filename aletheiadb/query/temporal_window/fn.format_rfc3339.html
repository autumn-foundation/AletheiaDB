pub fn format_rfc3339(micros: i64) -> String
Expand description

Format a microsecond timestamp as an RFC 3339 UTC string (Z suffix, microsecond precision), mirroring the MCP surface’s convention. Falls back to a <micros>us token if the value is outside chrono’s representable range.
