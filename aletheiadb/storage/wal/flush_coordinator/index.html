Module flush_coordinator 

Source
Expand description

Flush coordinator for the concurrent WAL.

The flush coordinator is responsible for:

  • Draining entries from all stripes
  • Sorting entries by LSN to restore global order
  • Writing entries to segment files
  • Performing fsync based on durability mode
  • Notifying completion handles after durable writes

§Architecture

The coordinator runs as a background thread that periodically flushes pending entries. It can also be triggered immediately for sync commits.

┌─────────────────────────────────────────────────────────┐
│                  Flush Coordinator                       │
│  ┌─────────────────────────────────────────────────┐   │
│  │  1. Drain all stripes                            │   │
│  │  2. Sort by LSN                                  │   │
│  │  3. Write to segment file                        │   │
│  │  4. fsync (if required by durability mode)       │   │
│  │  5. Notify completion handles                    │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘

§Thread Safety

The coordinator is designed to be run from a single thread. Multiple threads should not call flush() concurrently.
