RPC client implementation for shard-to-shard communication.

This module provides a production-ready HTTP-based RPC client that implements the ShardClient trait. It uses reqwest for HTTP transport and JSON serialization for protocol messages.

§Feature Flags

This module requires the sharding-rpc feature to be enabled:

[dependencies]
aletheiadb = { version = "0.1", features = ["sharding-rpc"] }

§Example

ⓘ
use aletheiadb::storage::sharding::rpc_client::{HttpShardClient, RpcConfig};

let config = RpcConfig {
    endpoint: "http://shard0:9000".to_string(),
    timeout: Duration::from_secs(30),
    ..Default::default()
};

let client = HttpShardClient::new(ShardId::new(0).unwrap(), config)?;
let state = client.get_state()?;
