Maximum size of a string interner file (DoS protection).

Limits the amount of memory allocated when loading the string interner. Test limit increased to 20MB to allow testing string length validation (MAX_STRING_LENGTH is 10MB, need buffer for encoding overhead). Default: 256MB in production, 20MB in tests.
