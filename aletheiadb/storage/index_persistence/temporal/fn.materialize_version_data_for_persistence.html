Function materialize_version_data_for_persistence 

Source 
pub fn materialize_version_data_for_persistence(
    data: &VersionData,
    base: &PropertyMap,
) -> Result<VersionData>
Expand description

Return a copy of data with all vector deltas materialized against base (the fully reconstructed property state of the previous version), ready for persistence. The live in-memory version is never mutated – only the persisted copy carries the materialized (Full) vectors.

§Errors

Returns an error if a sparse delta cannot be resolved against base (missing or non-vector base property) – persisting it anyway would be silent data loss.
