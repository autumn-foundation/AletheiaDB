Module legacy_v1

Expand description

Frozen copies of the temporal index structs as they existed before write-time provenance (Issue #3224) was added, i.e. MANIFEST_VERSION == 1.

bitcode is a positional, non-self-describing format: appending a field to NodeVersionEntry/EdgeVersionEntry changes their wire layout, so files written by older binaries can no longer decode as the current structs. These frozen shapes let super::temporal::load_temporal_index fall back to the old layout and upgrade in memory (provenance: None).

Do not modify these types after they’re introduced – they exist purely to describe historical on-disk bytes.
