Module semantic_search 

Source
Expand description

Semantic Search: retrieval, matching, clustering, traversal, entity resolution.

Given a query (vector, seed node, or pattern), find/rank/navigate to relevant nodes and subgraphs by combining vector similarity with graph topology.

§Status

Stable in 0.1 — graduated from experimental::* (“Nova”) after the usearch integration landed. The API may still evolve before 1.0, but breaking changes will follow normal semver.

§Enabling

[dependencies]
aletheiadb = { version = "0.1", features = ["semantic-search"] }
