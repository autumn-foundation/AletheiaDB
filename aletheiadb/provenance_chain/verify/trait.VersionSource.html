Expand description

Reconstructs the authoritative, hashable form of a specific version.

Implemented against whatever holds the real version content (the historical store at runtime, or a synthetic map in tests). Returning None means the referenced version cannot be found, which fails verification.

fn scoped(&self, f: &mut dyn FnMut(&dyn VersionSource))

Run f against a fetch view for the duration of one verification pass, giving a lock-backed source the chance to acquire its underlying shared lock once for the whole pass instead of re-locking on every fetch (Issue #3351 AC4 / task #2).

The default implementation simply runs f against self — correct for any source whose fetch is already cheap/lock-free (e.g. an in-memory test map). A source that guards real storage behind a RwLock overrides this to hold its read guard across f, so a full/entity verify takes the read lock a single time rather than once per version.
