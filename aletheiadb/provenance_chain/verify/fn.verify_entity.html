Expand description

Entity-scoped verification: recompute only entity’s leaves via src and confirm, for each touching record, that the sealed leaf matches and the record’s own digest folds consistently from its (stored) predecessor.

No full scan of the chain — only the records that reference entity.

Like verify_full, routes through VersionSource::scoped so the live historical store is locked once for the (already entity-scoped) pass.
