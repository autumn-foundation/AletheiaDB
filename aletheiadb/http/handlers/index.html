Expand description

HTTP request handlers for the AletheiaDB JSON API.

Two public route handlers are exposed:

  • GET /status → health_check
  • POST /query → handle_query (polymorphic JSON payload, see QueryRequest)

§Example Request

{
  "operation": "find_node",
  "label": "Person",
  "properties": { "name": "Alice" }
