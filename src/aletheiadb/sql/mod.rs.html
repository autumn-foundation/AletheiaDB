1//! SQL:2011 Temporal Syntax Support for AletheiaDB
2//!
3//! This module provides SQL query language support with SQL:2011 temporal extensions,
4//! enabling developers to query the database using familiar SQL syntax while maintaining
5//! full bi-temporal capabilities.
6//!
7//! # Feature Flag
8//!
9//! This module is only available when the `sql` feature is enabled:
10//!
11//! ```toml
12//! [dependencies]
13//! aletheiadb = { version = "0.1", features = ["sql"] }
14//! ```
15//!
16//! # Architecture
17//!
18//! ```text
19//! SQL String → [sqlparser] → SQL AST → [SqlConverter] → Query → [Planner] → Results
20//! ```
21//!
22//! # Quick Start
23//!
24//! ```rust,ignore
25//! use aletheiadb::sql::parse_sql;
26//!
27//! // Basic query
28//! let query = parse_sql("SELECT * FROM nodes WHERE label = 'Person' LIMIT 10")?;
29//!
30//! // Temporal query (SQL:2011)
31//! let query = parse_sql(
32//!     "SELECT * FROM nodes FOR SYSTEM_TIME AS OF TIMESTAMP '2024-01-15 10:00:00'"
33//! )?;
34//! ```
35//!
36//! # Supported Syntax
37//!
38//! ## Phase 1: Basic SQL
39//! - `SELECT` with column projection
40//! - `FROM nodes` / `FROM edges` table references
41//! - `WHERE` with comparison and logical operators
42//! - `ORDER BY` with ASC/DESC
43//! - `LIMIT` and `OFFSET`
44//!
45//! ## Phase 2: Temporal Extensions (SQL:2011)
46//! - `FOR SYSTEM_TIME AS OF timestamp` - Point-in-time query
47//! - `FOR SYSTEM_TIME BETWEEN t1 AND t2` - Time range query
48//! - `FOR VALID_TIME AS OF timestamp` - Valid time query
49//!
50//! ## Phase 3: Graph Extensions
51//! - `MATCH (source)-[:EDGE_TYPE*1..3]->(target)` - Path traversal
52//!
53//! ## Phase 4: Vector Extensions
54//! - `ORDER BY embedding <=> '[0.1, 0.2, ...]'::vector LIMIT 10` - k-NN search
