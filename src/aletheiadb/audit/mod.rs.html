1//! Signed audit export of entity history for compliance (Issue #3358).
2//!
3//! Turns AletheiaDB's storage-layer trust into portable, offline-verifiable
4//! evidence: a single-file artifact containing an entity's complete bi-temporal
5//! history plus provenance, signed so a third party with only the signer's
6//! **public key** can verify — with no database, no network, and no trust in the
7//! operator — that (a) no content was altered after export and (b) the content
8//! is complete (nothing was added, removed, or reordered).
9//!
10//! # Why Ed25519 (asymmetric) rather than an HMAC
11//!
12//! Verification must be possible for a party who has *only the signer's public
13//! key*. A symmetric MAC would require the verifier to hold the same secret the
14//! signer holds — so the operator could forge artifacts and a third party could
15//! not independently trust them. Ed25519 detached signatures over a SHA-256 hash
16//! chain give offline, public-key-only verification with reproducible signatures.
17//!
18//! # Artifact + verification contract
19//!
20//! The artifact is JSON ([`AuditExport`]). Its signature is computed over a
21//! deterministic canonical *binary* encoding of the typed content (not the JSON
22//! text), so reformatting is safe but any content change is caught. See the
23//! [`canonical`] module and `docs/guides/audit-export.md` for the fully
24//! documented, independently-implementable format.
25//!
26//! # Quick start
27//!
28//! ```no_run
29//! use aletheiadb::AletheiaDB;
30//! use aletheiadb::audit::{AuditScope, AuditSigningKey, ExportOptions, verify_json_bytes};
31//! # fn main() -> Result<(), Box<dyn std::error::Error>> {
32//! let db = AletheiaDB::new()?;
33//! let node = db.create_node("Person", aletheiadb::PropertyMap::new())?;
34//!
35//! let key = AuditSigningKey::generate();
36//! let export = db.audit_export(AuditScope::node(node), &key, &ExportOptions::new("prod-db"))?;
37//! let bytes = export.to_json_bytes()?;
38//!
39//! // Offline: only the bytes + the public key.
40//! let report = verify_json_bytes(&bytes, Some(&key.public_key()))?;
41//! assert!(report.passed);
42//! # Ok(())
43//! # }
44//! ```
45//!
46//! # Known limitation (#3427)
47//!
48//! Delete/retract operations do not yet stamp an authenticated principal into
49//! provenance. The export surfaces provenance faithfully — including its absence
50//! on delete tombstones — and never fabricates attribution. This is documented
51//! honestly rather than papered over.
