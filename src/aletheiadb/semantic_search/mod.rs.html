1//! Semantic Search: retrieval, matching, clustering, traversal, entity resolution.
2//!
3//! Given a query (vector, seed node, or pattern), find/rank/navigate to relevant
4//! nodes and subgraphs by combining vector similarity with graph topology.
5//!
6//! # Status
7//!
8//! Stable in 0.1 — graduated from `experimental::*` ("Nova") after the usearch
9//! integration landed. The API may still evolve before 1.0, but breaking changes
10//! will follow normal semver.
11//!
12//! # Enabling
13//!
14//! ```toml
15//! [dependencies]
16//! aletheiadb = { version = "0.1", features = ["semantic-search"] }
17//! ```
18//!
19//! # Module Inventory
20//!
21//! | Module | Description |
22//! |--------|-------------|
23//! | [`fishing`] | Associative retrieval (vector + graph + freshness) |
24//! | [`gestalt`] | Fuzzy semantic subgraph pattern matching |
25//! | [`cartographer`] | Semantic clustering / region reification |
26//! | [`highlander`] | Entity resolution / semantic dedup |
27//! | [`janus`] | Semantic bridge detection between clusters |
28//! | [`chameleon`] | Context-aware faceted search |
29//! | [`semantic_navigator`] | Vector-guided A* pathfinding |
30//! | [`concept_algebra`] | Vector arithmetic primitives (query construction) |
31//! | [`serendipity`] | Divergence-maximizing scenic traversal |
32//! | [`voyager`] | Novelty-maximizing traversal |
33//! | [`spectre`] | Subjective/perspective-based traversal |
34//! | [`telepathy`] | Spreading activation engine |
35//! | [`tapestry`] | Semantic path weaving |
36//! | [`horizon`] | Concept boundary / semantic event horizon |
37//! | `mosaic` | Compositional search (build target from a set of nodes) |
