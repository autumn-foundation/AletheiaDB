1//! Cold-tier (redb) key ring and self-describing value wrapper (Issue #3617 PR3).
2//!
3//! A full-MEK key rotation re-keys the cold tier by a **transactional bulk
4//! re-encrypt** of every stored value: each `node_versions`/`edge_versions`
5//! value is decrypted under the OLD cold DEK and re-encrypted under the NEW cold
6//! DEK. To read correctly during (and after) such a rotation the cold store must
7//! hold BOTH generations at once and select per value, exactly like the WAL
8//! ([`WalKeyring`](crate::encryption::wal_encryption::WalKeyring)) and index
9//! ([`IndexKeyring`](crate::storage::index_persistence::common::IndexKeyring))
10//! keyrings. [`ColdKeyring`] is that holder, deliberately mirroring their shape
11//! (a small `Vec` of generations, a `current` stamped into freshly written
12//! values, and a single-cipher `match_any` back-compat mode).
13//!
14//! # Self-describing value wrapper (`ACV1`)
15//!
16//! Cold values are compress-then-encrypt with empty AAD, and a legacy value is
17//! opaque AEAD ciphertext whose leading bytes are effectively random — so a bare
18//! 1-byte discriminator would be ambiguous. Re-encrypted values are therefore
19//! prefixed with an 8-byte self-describing header:
20//!
21//! ```text
22//! Wrapped value:  [magic "ACV1":4][key_version:u32 LE:4][ AEAD(compress(record)) ]
23//! Legacy value:   [ AEAD(compress(record)) ]            # exactly the pre-#3617 format
24//! ```
25//!
26//! Read dispatch ([`parse_cold_wrapper`] in front of decrypt): a value is
27//! treated as wrapped ONLY IF it begins with `ACV1` **and** the following `u32`
28//! names a generation the live keyring holds ([`has_version`](ColdKeyring::has_version));
29//! otherwise it is treated as a legacy bare ciphertext and decrypted under the
30//! oldest (pre-rotation) cold generation.
31//!
32//! ## False-positive probability (be precise: it depends on the keyring mode)
33//!
34//! How much the second check (the held-version test) actually discriminates
35//! depends on whether the keyring is in `match_any` or strict mode — and the
36//! common case is the *weaker* one:
37//!
38//! * **Single-generation `match_any` keyring** — the never-rotated steady state,
39//!   and the post-provider-switch state after a completed rotation (the operator
40//!   reopens under the new key alone). Here [`has_version`](ColdKeyring::has_version)
41//!   **short-circuits `true` for every `key_version`**, so the held-version test
42//!   adds **no** discrimination: a legacy bare ciphertext is misclassified as
43//!   wrapped as soon as its first 4 bytes happen to equal the `ACV1` magic —
44//!   probability **~2⁻³²** (NOT 2⁻⁶⁴). The trailing `u32` is irrelevant to the
45//!   classification in this mode.
46//! * **Strict (mid-rotation, 2-generation) keyring** — only here does the
47//!   held-version test bite: the leading 4 bytes must equal `ACV1` (~2⁻³²) AND
48//!   the next 4 bytes must equal one of the tiny set of currently-held key
49//!   versions (~2⁻³²), a combined **~2⁻⁶⁴** event. The 2⁻⁶⁴ figure applies to
50//!   this mode ONLY.
51//!
52//! Crucially, in **either** mode a misclassification is a **loud AEAD
53//! authentication failure** — the wrong byte slice is fed to `decrypt`, the tag
54//! check fails, and the read returns an `Err` (a read *availability* fault). It
55//! is **NEVER** silent wrong data or integrity loss: a corrupted/misparsed value
56//! cannot forge a valid AEAD tag, so no plaintext is ever returned for it. The
57//! ~2⁻³² event therefore costs *availability of that one value* (recoverable by
58//! reopening under the correct key), not correctness. The same 4-byte-magic
59//! collision argument is used one layer down by [`COLD_RECORD_MAGIC_V2`](super)
60//! for the in-record provenance tag.
61//!
62//! No key material is ever written into the wrapper (a `key_version` integer
63//! only), logged, or rendered by `Debug`.
64
65use std::sync::{Arc, RwLock};
66
67use crate::encryption::Cipher;

69/// Magic prefix identifying an `ACV1`-wrapped cold value. Deliberately the
70/// printable ASCII `b"ACV1"` (**A**letheia **C**old **V**alue v**1**), distinct
71/// from the record-level [`COLD_RECORD_MAGIC_V2`](super::COLD_RECORD_MAGIC_V2)
72/// `[0xA1,0x37,0xC0,0xDE]` / [`COLD_RECORD_MAGIC_V3`](super::COLD_RECORD_MAGIC_V3)
73/// `[0xB2,0x48,0xD1,0xEF]` — those tag the *record* inside the ciphertext, this
74/// tags the *stored value* outside it, so they never occupy the same byte
75/// position, but keeping the values disjoint avoids any reviewer confusion.
76pub(super) const COLD_VALUE_MAGIC: [u8; 4] = *b"ACV1";
77
78/// Total length of the `ACV1` wrapper prefix (4-byte magic + 4-byte key_version).
79pub(super) const COLD_VALUE_WRAPPER_LEN: usize = 8;
80
81/// The `key_version` a fresh (never-rotated) encrypted cold store stamps into
82/// its `ACV1` value wrappers. Mirrors [`INITIAL_WAL_KEY_VERSION`] /
83/// `ENC_INDEX_KEY_VERSION_V1` so all three layers number their first generation
84/// identically.
85///
86/// [`INITIAL_WAL_KEY_VERSION`]: crate::encryption::wal_encryption::INITIAL_WAL_KEY_VERSION
87pub(super) const INITIAL_COLD_KEY_VERSION: u32 = 1;
88
89/// Prepend the `ACV1` wrapper to an AEAD ciphertext, stamping `key_version`.
90pub(super) fn wrap_cold_value(key_version: u32, ciphertext: &[u8]) -> Vec<u8> {
91    let mut out = Vec::with_capacity(COLD_VALUE_WRAPPER_LEN + ciphertext.len());
92    out.extend_from_slice(&COLD_VALUE_MAGIC);
93    out.extend_from_slice(&key_version.to_le_bytes());
94    out.extend_from_slice(ciphertext);
95    out
96}
97
98/// If `value` begins with the `ACV1` magic and is long enough to carry the
99/// key-version, return `(key_version, ciphertext_without_wrapper)`; otherwise
100/// `None` (a legacy, unwrapped value). This does NOT consult the keyring — the
101/// caller checks whether the returned `key_version` names a held generation and
102/// falls back to the legacy path if not.
103pub(super) fn parse_cold_wrapper(value: &[u8]) -> Option<(u32, &[u8])> {
104    if value.len() < COLD_VALUE_WRAPPER_LEN || value[..4] != COLD_VALUE_MAGIC {
105        return None;
106    }
107    let key_version = u32::from_le_bytes([value[4], value[5], value[6], value[7]]);
108    Some((key_version, &value[COLD_VALUE_WRAPPER_LEN..]))
109}

111#[derive(Clone)]
112struct ColdKeyGeneration {
113    key_version: u32,
114    cipher: Arc<dyn Cipher>,
115}
116
117struct ColdKeyringInner {
118    /// All live generations (1 before rotation, 2 during, 1 after). Small.
119    generations: Vec<ColdKeyGeneration>,
120    /// Version stamped into freshly written values (the newest generation).
121    current_version: u32,
122    /// Back-compat mode: a lone generation created from a single cipher decrypts
123    /// ANY value (any `key_version`, or a legacy value carrying no wrapper) with
124    /// that one cipher. This is the never-rotated steady state and, crucially,
125    /// the post-provider-switch state: after a completed rotation the operator
126    /// reopens under the new key alone, so the single new-DEK keyring must still
127    /// read the new-DEK values regardless of the `key_version` they were stamped
128    /// with during the rotation.
129    match_any: bool,
130}
131
132/// A cheaply-cloneable, shared-mutable set of cold DEK ciphers addressed by
133/// `key_version` (Issue #3617 PR3).
134///
135/// Clones share the same underlying state, so the rotation driver can advance
136/// the current generation (making new writes stamp + encrypt under the new DEK)
137/// while readers holding clones observe the change immediately. Never exposes
138/// key material; `Debug` is redacted.
139#[derive(Clone)]
140pub struct ColdKeyring {
141    inner: Arc<RwLock<ColdKeyringInner>>,
142}
143
144impl std::fmt::Debug for ColdKeyring {
145    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
146        // Never render key material — only opaque generation metadata.
147        let inner = self.inner.read().unwrap_or_else(|e| e.into_inner());
148        f.debug_struct("ColdKeyring")
149            .field("generations", &inner.generations.len())
150            .field("current_version", &inner.current_version)
151            .field("match_any", &inner.match_any)
152            .finish()
153    }
154}
155
156impl ColdKeyring {
157    /// A single-generation keyring from one cipher (the non-rotation path).
158    ///
159    /// Reads decrypt any value (any wrapper `key_version`, or a legacy value with
160    /// no wrapper) with this cipher and writes stamp
161    /// [`INITIAL_COLD_KEY_VERSION`].
162    pub fn single(cipher: Arc<dyn Cipher>) -> Self {
163        Self::single_versioned(cipher, INITIAL_COLD_KEY_VERSION)
164    }
165
166    /// A single-generation cold keyring pinned to an explicit `key_version`
167    /// (Issue #488 version-provisioning parity). Reads decrypt every value with
168    /// this one cipher (`match_any`, byte-identical to [`Self::single`]); only
169    /// the write-stamp / reported [`current_version`](Self::current_version) is
170    /// pinned to `key_version`. The durable `open()` path builds the cold keyring
171    /// at the provisioned key version so freshly written values stamp the real
172    /// version instead of a stale [`INITIAL_COLD_KEY_VERSION`], keeping the cold
173    /// layer in lockstep with index/WAL after a rotate-then-reopen.
174    pub fn single_versioned(cipher: Arc<dyn Cipher>, key_version: u32) -> Self {
175        Self {
176            inner: Arc::new(RwLock::new(ColdKeyringInner {
177                generations: vec![ColdKeyGeneration {
178                    key_version,
179                    cipher,
180                }],
181                current_version: key_version,
182                match_any: true,
183            })),
184        }
185    }
186
187    /// The current (write) cipher and the `key_version` it stamps into new value
188    /// wrappers, or `None` if the keyring somehow holds no generation.
189    pub fn current(&self) -> Option<(Arc<dyn Cipher>, u32)> {
190        let inner = self.inner.read().unwrap_or_else(|e| e.into_inner());
191        let v = inner.current_version;
192        inner
193            .generations
194            .iter()
195            .find(|g| g.key_version == v)
196            .map(|g| (g.cipher.clone(), v))
197    }
198
199    /// The version freshly written values are stamped with.
200    pub fn current_version(&self) -> u32 {
201        self.inner
202            .read()
203            .unwrap_or_else(|e| e.into_inner())
204            .current_version
205    }
206
207    /// Resolve the decryption cipher for a value, given the `key_version` read
208    /// from its wrapper (`Some` for an `ACV1`-wrapped value, `None` for a legacy
209    /// value that carries no wrapper).
210    ///
211    /// * `match_any` (single-cipher) keyring → the sole cipher for every value
212    ///   (never-rotated / post-switch steady state).
213    /// * strict keyring, legacy value (`None`) → the OLDEST (minimum-version,
214    ///   i.e. pre-rotation) generation — the DEK legacy values were written under
215    ///   before the rotation advanced the generation.
216    /// * strict keyring, `Some(kv)` → the generation stamped `kv`, or `None` when
217    ///   no such generation is held (a genuine wrong/absent key surfaces as a loud
218    ///   AEAD failure downstream rather than silent wrong data).
219    pub(super) fn cipher_for_value(&self, key_version: Option<u32>) -> Option<Arc<dyn Cipher>> {
220        let inner = self.inner.read().unwrap_or_else(|e| e.into_inner());
221        if inner.match_any {
222            return inner.generations.first().map(|g| g.cipher.clone());
223        }
224        match key_version {
225            Some(kv) => inner
226                .generations
227                .iter()
228                .find(|g| g.key_version == kv)
229                .map(|g| g.cipher.clone()),
230            None => inner
231                .generations
232                .iter()
233                .min_by_key(|g| g.key_version)
234                .map(|g| g.cipher.clone()),
235        }
236    }
237
238    /// Whether a generation with `key_version` is currently held (a `match_any`
239    /// single keyring holds every version).
240    pub(super) fn has_version(&self, key_version: u32) -> bool {
241        let inner = self.inner.read().unwrap_or_else(|e| e.into_inner());
242        inner.match_any
243            || inner
244                .generations
245                .iter()
246                .any(|g| g.key_version == key_version)
247    }
248
249    /// Add a new generation and make it current. Switches the keyring to strict
250    /// per-version dispatch (leaving `match_any`). Idempotent for a version
251    /// already present (its cipher is replaced). Used by the rotation driver to
252    /// install the new cold DEK before the bulk re-encrypt pass.
253    pub(super) fn add_generation(&self, key_version: u32, cipher: Arc<dyn Cipher>) {
254        let mut inner = self.inner.write().unwrap_or_else(|e| e.into_inner());
255        inner.match_any = false;
256        inner.generations.retain(|g| g.key_version != key_version);
257        inner.generations.push(ColdKeyGeneration {
258            key_version,
259            cipher,
260        });
261        inner.current_version = key_version;
262    }
263
264    /// Retire every generation except `key_version`, which becomes the sole,
265    /// current generation. Used by the rotation driver at completion once every
266    /// value is re-wrapped under the new generation, so the old cold DEK can be
267    /// dropped.
268    pub(super) fn retain_only(&self, key_version: u32) {
269        let mut inner = self.inner.write().unwrap_or_else(|e| e.into_inner());
270        inner.generations.retain(|g| g.key_version == key_version);
271        inner.current_version = key_version;
272        inner.match_any = false;
273    }
274}
