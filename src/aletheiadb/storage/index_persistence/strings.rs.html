1//! String interner persistence.
2//!
3//! This module handles the serialization and deserialization of the [`GLOBAL_INTERNER`].
4//! The interner is critical for the database's operation as it maps all string labels and property keys to
5//! compact integer IDs.
6//!
7//! # Format
8//!
9//! The interner is saved as a Bitcode-encoded [`StringInternerData`] struct,
10//! followed by a 4-byte CRC32 checksum.
11//!
12//! ```text
13//! [ Bitcode Encoded Data ] [ CRC32 (4 bytes) ]
14//! ```
15//!
16//! # Safety
17//!
18//! Restoring the string interner **must** be the first step during database recovery. All other
19//! persistence files (like vector indexes or adjacency lists) refer to strings by their interned IDs.
20//! If the interner is not restored to the exact same state, these IDs will map to incorrect strings,
21//! causing data corruption.
22

35/// Sentinel live id used when a persisted file-space interner id cannot be
36/// mapped through the remap (i.e. it references a position past the end of the
37/// saved interner file — genuine on-disk corruption). It is never a valid
38/// interner id in practice, so downstream resolution of a property key / string
39/// value / label stamped with it deterministically *fails* (the node/edge is
40/// skipped and counted as a load error) rather than silently resolving to some
41/// unrelated live string. This preserves corruption detection while the remap
42/// eliminates the benign file-id vs live-id divergence that Issue #3490 was.
43const UNMAPPABLE_FILE_ID: u32 = u32::MAX;
44
45/// Translation table from **persisted file-space interner ids** to **live
46/// interner ids**, produced by [`restore_string_interner`].
47///
48/// # Why this exists (Issue #3490)
49///
50/// Persistence stores raw `u32` interner ids for property keys, string values,
51/// and node/edge labels. Those ids are assigned by the process-global
52/// [`GLOBAL_INTERNER`] in first-intern order, so they are only meaningful
53/// relative to the interner state that produced them. The saved interner file
54/// records the strings in that id order (position `i` == the string that had
55/// interner id `i` at save time).
56///
57/// On reload the live interner is generally **not** pristine, so re-interning
58/// the saved strings yields *different* live ids than the file positions they
59/// were saved at. Two mechanisms make the live interner diverge from the saved
60/// file order before [`restore_string_interner`] runs:
61///
62/// 1. **WAL bootstrap deserialization.** During startup, `wal.read_from`
63///    (`src/db/config.rs`) deserializes the on-disk WAL entries, and
64///    `PropertyMap::deserialize` (`src/core/property/map.rs`) interns every
65///    property **key** it decodes into the process-global interner. This
66///    happens *before* the saved interner file is restored, so the keys land at
67///    whatever ids the interner hands out next — not the ids they had when the
68///    interner file was written. (WAL bootstrap is a raw deserialize, not a
69///    differential replay: the differential WAL replay proper runs *after*
70///    `load_indexes_startup`, and it does not intern.)
71/// 2. **The interner is a process-global singleton.** `GLOBAL_INTERNER` is
72///    shared across every `AletheiaDB` instance and every `open()` in the
73///    process, so any prior or concurrent population (earlier opens, other
74///    instances) leaves it already holding strings at ids unrelated to any one
75///    saved file.
76///
77/// Either way, the string at file position `i` re-interns to some live id that
78/// is generally not `i`. The old restore path asserted positional identity and
79/// aborted with an `InternerMismatch`, which was swallowed to a warning and
80/// silently abandoned the whole graph index — dropping data.
81///
82/// The fix decouples the two id namespaces: the saved interner file defines a
83/// **file-local** id space, and this remap translates each persisted file id to
84/// the live id the same string actually has in this process. Every persisted
85/// `u32` interner id (keys, string values, labels, `removed_keys`) must be
86/// routed through [`InternerRemap::remap_id`] before being resolved against the
87/// live interner. The on-disk wire format is unchanged — this is purely a
88/// load-time interpretation fix.
89///
90/// # Positional-identity invariant
91///
92/// The remap assumes `data.strings[i]` is exactly the string whose live id was
93/// `i` when the interner file was saved. That holds only because
94/// [`StringInterner::get_all_strings`](crate::core::interning::StringInterner::get_all_strings)
95/// (`src/core/interning.rs`) `.flatten()`s the id-ordered slot table, and the
96/// interner only ever leaves **tail** holes (capacity rollbacks), never
97/// interior ones — so flattening drops only trailing empty slots and preserves
98/// the position == id coupling for every retained string. If that ever changes
99/// (interior holes), this remap and `get_all_strings` would need to co-evolve.
100///
101/// An [`InternerRemap::identity`] variant (used when no interner file was
102/// loaded) passes ids through unchanged, exactly reproducing legacy behavior.
103#[derive(Debug, Clone, Default)]
104pub struct InternerRemap {
105    /// `mapping[file_position]` == the live [`InternedString`] the saved string
106    /// at that position resolves to in this process. `None` == identity remap
107    /// (no translation; every id passes through unchanged).
108    mapping: Option<Vec<InternedString>>,
109}
110
111impl InternerRemap {
112    /// An identity remap: every persisted id is used verbatim as a live id.
113    ///
114    /// Used when there is no saved interner file to translate against (e.g. a
115    /// first run, or best-effort recovery where the interner file is absent),
116    /// preserving the exact pre-#3490 behavior for those paths.
117    pub fn identity() -> Self {
118        Self { mapping: None }
119    }
120
121    /// Build a remap from the saved strings, in file order.
122    ///
123    /// `positions[i]` is the live id that the string at file position `i`
124    /// resolves to after being interned into the current [`GLOBAL_INTERNER`].
125    fn from_positions(positions: Vec<InternedString>) -> Self {
126        Self {
127            mapping: Some(positions),
128        }
129    }
130
131    /// Translate a persisted file-space interner id to its live id.
132    ///
133    /// Returns `None` when a mapping remap does not cover `file_id` (the id
134    /// points past the end of the saved interner file — genuine corruption).
135    /// Identity remaps always return `Some` (the id verbatim).
136    pub fn resolve(&self, file_id: u32) -> Option<InternedString> {
137        match &self.mapping {
138            None => Some(InternedString::from_raw(file_id)),
139            Some(positions) => positions.get(file_id as usize).copied(),
140        }
141    }
142
143    /// Translate a persisted file-space id to a live id as a raw `u32`,
144    /// substituting [`UNMAPPABLE_FILE_ID`] for an out-of-range (corrupt) id so
145    /// that later resolution fails loudly instead of returning wrong data.
146    fn remap_id(&self, file_id: u32) -> u32 {
147        self.resolve(file_id)
148            .map(|id| id.as_u32())
149            .unwrap_or(UNMAPPABLE_FILE_ID)
150    }
151
152    /// Rewrite every interner id embedded in a persisted property map from
153    /// file space to live space (property keys and any `String` values).
154    fn remap_property_map(&self, map: &mut PersistedPropertyMap) {
155        for (key_idx, value) in map.entries.iter_mut() {
156            *key_idx = self.remap_id(*key_idx);
157            if let PersistedPropertyValue::String(value_idx) = value {
158                *value_idx = self.remap_id(*value_idx);
159            }
160        }
161    }
162
163    /// Rewrite every persisted interner id in a loaded [`GraphIndexData`] in
164    /// place, so the existing restore path (which resolves ids against the live
165    /// interner) sees live ids. Covers node/edge labels and node/edge property
166    /// maps (keys + string values).
167    ///
168    /// An identity remap leaves the data byte-for-byte unchanged.
169    pub fn remap_graph_index_data(&self, data: &mut GraphIndexData) {
170        if self.mapping.is_none() {
171            return;
172        }
173        for node in data.nodes.iter_mut() {
174            node.label_idx = self.remap_id(node.label_idx);
175            self.remap_property_map(&mut node.properties);
176        }
177        for edge in data.edges.iter_mut() {
178            edge.label_idx = self.remap_id(edge.label_idx);
179            self.remap_property_map(&mut edge.properties);
180        }
181    }
182
183    /// Rewrite every persisted interner id in a loaded [`TemporalIndexData`] in
184    /// place. Covers node/edge version labels, version property maps (keys +
185    /// string values), the `removed_keys` of delta versions, and the anchor
186    /// `full_state` property maps.
187    ///
188    /// An identity remap leaves the data byte-for-byte unchanged.
189    pub fn remap_temporal_index_data(&self, data: &mut TemporalIndexData) {
190        if self.mapping.is_none() {
191            return;
192        }
193        for version in data.node_versions.iter_mut() {
194            version.label_idx = self.remap_id(version.label_idx);
195            self.remap_property_map(&mut version.properties);
196            if let PersistedVersionType::Delta { removed_keys, .. } = &mut version.version_type {
197                for key_idx in removed_keys.iter_mut() {
198                    *key_idx = self.remap_id(*key_idx);
199                }
200            }
201        }
202        for version in data.edge_versions.iter_mut() {
203            version.label_idx = self.remap_id(version.label_idx);
204            self.remap_property_map(&mut version.properties);
205            if let PersistedVersionType::Delta { removed_keys, .. } = &mut version.version_type {
206                for key_idx in removed_keys.iter_mut() {
207                    *key_idx = self.remap_id(*key_idx);
208                }
209            }
210        }
211        for anchor in data.node_anchors.iter_mut() {
212            self.remap_property_map(&mut anchor.full_state);
213        }
214        for anchor in data.edge_anchors.iter_mut() {
215            self.remap_property_map(&mut anchor.full_state);
216        }
217    }
218
219    /// Rewrite every persisted edge-type interner id in a loaded
220    /// [`TemporalAdjacencyData`] in place. Each `PersistedTemporalAdjacencyEntry`
221    /// stores its edge-type `label` as a file-space interner id; this translates
222    /// it to the live id so the #3225 AS-OF temporal-traversal edge-type filter
223    /// (which compares the entry `label` against a live [`InternedString`])
224    /// matches the correct edge type after reload (Issue #3490).
225    ///
226    /// An unmappable (corrupt/out-of-range) file id becomes
227    /// [`UNMAPPABLE_FILE_ID`], which fails the live-interner resolve check in
228    /// the reconstruction step (that entry is skipped and counted loudly)
229    /// rather than being stored as a garbage edge type.
230    ///
231    /// An identity remap leaves the data byte-for-byte unchanged.
232    pub fn remap_temporal_adjacency_data(&self, data: &mut TemporalAdjacencyData) {
233        if self.mapping.is_none() {
234            return;
235        }
236        for node_entry in data.outgoing.iter_mut() {
237            for entry in node_entry.entries.iter_mut() {
238                entry.label = self.remap_id(entry.label);
239            }
240        }
241    }
242}

377/// Validate a decoded string-interner payload (magic, version, DoS limits).
378fn validate_string_interner(data: StringInternerData, path: &Path) -> Result<StringInternerData> {
379    // Validate magic bytes
380    if data.magic != INTERNER_MAGIC {
381        return Err(IndexPersistenceError::InvalidMagic {
382            path: path.to_path_buf(),
383            expected: INTERNER_MAGIC,
384            got: data.magic,
385        });
386    }
387
388    // Validate version
389    if data.version > MANIFEST_VERSION {
390        return Err(IndexPersistenceError::UnsupportedVersion {
391            found: data.version,
392            supported: MANIFEST_VERSION,
393        });
394    }
395
396    // Validate string count to prevent DoS via memory exhaustion.
397    //
398    // The effective limit honors the runtime cap configured at `open()` from
399    // `persistence.max_interned_strings` (set on GLOBAL_INTERNER before indexes
400    // load), floored by the generous `MAX_STRING_COUNT` backstop. This keeps the
401    // two caps in lockstep: a database that raised the runtime cap and interned
402    // past the old default reopens cleanly instead of being rejected here.
403    let effective_max = super::MAX_STRING_COUNT.max(GLOBAL_INTERNER.max_capacity() as u64);
404    if data.string_count > effective_max {
405        return Err(IndexPersistenceError::SizeLimitExceeded {
406            message: format!(
407                "String count {} exceeds maximum allowed count {}",
408                data.string_count, effective_max
409            ),
410        });
411    }
412
413    // Validate individual string lengths to prevent DoS
414    for s in &data.strings {
415        if s.len() > super::MAX_STRING_LENGTH {
416            return Err(IndexPersistenceError::SizeLimitExceeded {
417                message: format!(
418                    "String length {} exceeds maximum allowed length {}",
419                    s.len(),
420                    super::MAX_STRING_LENGTH
421                ),
422            });
423        }
424    }
425
426    Ok(data)
427}

429/// Restore the persisted strings into `GLOBAL_INTERNER`, returning a
430/// [`InternerRemap`] that translates persisted file-space ids to live ids.
431///
432/// This must be called before loading any other indexes since they reference
433/// string indices — but, crucially (Issue #3490), the caller must translate
434/// every persisted `u32` interner id through the returned [`InternerRemap`]
435/// (via [`InternerRemap::remap_graph_index_data`] /
436/// [`InternerRemap::remap_temporal_index_data`]) rather than resolving raw
437/// persisted ids directly against the live interner.
438///
439/// # File-id vs live-id contract
440///
441/// Each saved string is re-interned into the (possibly already-populated) live
442/// interner. Because WAL replay may have interned property keys in a different
443/// order before this runs, the live id assigned to the string at file position
444/// `i` is generally **not** `i`. This function records `file_position -> live
445/// id` for every saved string and returns it as the remap. It does **not**
446/// assert positional identity (the pre-#3490 behavior that spuriously failed
447/// with `InternerMismatch` and silently dropped the graph index).
448///
449/// Empty strings are interned like any other string; a saved `""` is a real
450/// interned empty string (holes are already filtered out by
451/// [`StringInterner::get_all_strings`](crate::core::interning::StringInterner::get_all_strings)
452/// before save), so its file position still needs a live mapping in case data
453/// references it.
454///
455/// # Examples
456///
457/// ```
458/// use aletheiadb::storage::index_persistence::strings::{save_string_interner, load_string_interner, restore_string_interner};
459/// use tempfile::tempdir;
460///
461/// let dir = tempdir().unwrap();
462/// let path = dir.path().join("interner.idx");
463///
464/// // Save current state
465/// save_string_interner(&path).unwrap();
466///
467/// // Load data
468/// let data = load_string_interner(&path).unwrap();
469///
470/// // Restore (re-interns all strings) and obtain the file-id -> live-id remap.
471/// let remap = restore_string_interner(&data).unwrap();
472/// let _ = remap; // apply to loaded graph/temporal indexes before resolving ids
473/// ```
474///
475/// # Errors
476///
477/// Currently infallible (returns `Ok`): persisted strings are re-admitted via
478/// `intern_unchecked`, which bypasses the runtime capacity cap, so a reopen
479/// under a cap lower than the persisted count loads cleanly instead of wedging.
480/// The `Result` return is retained for signature stability with the callers'
481/// `?` chains and to leave room for future validation.
482pub fn restore_string_interner(data: &StringInternerData) -> Result<InternerRemap> {
483    let mut positions = Vec::with_capacity(data.strings.len());
484    for s in &data.strings {
485        // Re-admit persisted strings via `intern_unchecked`, bypassing the
486        // runtime capacity cap (configurable interner cap fix). These strings
487        // were already admitted once when they were written, so restoring
488        // known-good on-disk data must NEVER be blocked by a runtime cap that is
489        // lower than the persisted count — that would wedge the whole reopen with
490        // a confusing "Failed to intern string" mid-load. The load-validation cap
491        // (`validate_string_interner`) still bounds the persisted COUNT up front,
492        // so a genuinely oversized file is rejected before we reach here; NEW
493        // interns on the live write path remain capped as normal.
494        let interned_id = GLOBAL_INTERNER.intern_unchecked(s);
495        // Record file_position (== `positions.len()`) -> live interner id. We do
496        // NOT require live id == file position: the live interner may already
497        // hold these strings (e.g. from WAL replay) at different ids. The remap
498        // captures whatever translation is needed so persisted ids resolve to
499        // the correct strings regardless of interning order (Issue #3490).
500        positions.push(interned_id);
501    }
502    Ok(InternerRemap::from_positions(positions))
503}

661    /// effective cap is `max(MAX_STRING_COUNT, GLOBAL_INTERNER.max_capacity())`,
662    /// so a persisted interner whose COUNT exceeds the 10M `MAX_STRING_COUNT`
663    /// floor must be REJECTED at the default cap and LOAD only after the runtime
664    /// cap is raised above it. This DISCRIMINATES the `max(...)` change (the old
665    /// test used a 200K count, which is below the 10M floor and would pass on

672        use std::process::Command;

676        let mut child = Command::new(exe)
677            .args([
678                "--ignored",
679                "--exact",
680                "storage::index_persistence::strings::tests::\
681                 string_count_above_floor_rejected_then_loads_under_raised_cap_helper",
682            ])
683            .spawn()
684            .expect("failed to spawn subprocess for load-cap discrimination test");
685
686        let deadline = Instant::now() + Duration::from_secs(30);

689                Ok(Some(status)) => {

698                    }
699                    std::thread::sleep(Duration::from_millis(20));
700                }
701                Err(e) => panic!("failed while polling subprocess: {e}"),
702            }

901    fn test_remap_graph_index_data_translates_polluted_order() {
902        use crate::storage::index_persistence::graph::{
903            new_graph_index_data, restore_property_map,
904        };
905
906        // Simulate save order: intern label + keys + a string value, capture the
907        // FILE ids in that order, then build a persisted node referencing them.
908        let suffix = std::time::SystemTime::now()
909            .duration_since(std::time::UNIX_EPOCH)
910            .unwrap()
911            .as_nanos();
912        let label = format!("RemapLabel_{suffix}");
913        let key_a = format!("remap_key_a_{suffix}");
914        let key_b = format!("remap_key_b_{suffix}");
915        let val = format!("remap_val_{suffix}");
916
917        let file_label = GLOBAL_INTERNER.intern(&label).unwrap().as_u32();
918        let file_key_a = GLOBAL_INTERNER.intern(&key_a).unwrap().as_u32();
919        let file_key_b = GLOBAL_INTERNER.intern(&key_b).unwrap().as_u32();
920        let file_val = GLOBAL_INTERNER.intern(&val).unwrap().as_u32();
921
922        let mut graph = new_graph_index_data();
923        graph.nodes.push(super::super::formats::PersistedNode {
924            id: 1,
925            label_idx: file_label,
926            version_id: 1,
927            properties: PersistedPropertyMap {
928                entries: vec![
929                    (file_key_a, PersistedPropertyValue::String(file_val)),
930                    (file_key_b, PersistedPropertyValue::Int(7)),
931                ],
932            },
933        });
934
935        // Build a remap whose file positions map to DIFFERENT live ids than the
936        // file ids above (mimicking WAL-replay pollution having shifted them).
937        // The saved interner file lists strings in the id order captured above.
938        // We can't easily control absolute live ids, so we assert behavior:
939        // after remapping, the node's ids resolve to the ORIGINAL strings.
940        let mut ordered = vec![String::new(); (file_val + 1) as usize];
941        // Fill positions that our node references so `from_positions`-style
942        // resolution is well-defined for them. Positions we don't reference are
943        // left empty (harmless).
944        ordered[file_label as usize] = label.clone();
945        ordered[file_key_a as usize] = key_a.clone();
946        ordered[file_key_b as usize] = key_b.clone();
947        ordered[file_val as usize] = val.clone();
948        let data = StringInternerData {
949            magic: INTERNER_MAGIC,
950            version: MANIFEST_VERSION,
951            string_count: ordered.len() as u64,
952            strings: ordered,
953        };
954        let remap = restore_string_interner(&data).unwrap();
955
956        remap.remap_graph_index_data(&mut graph);
957
958        // After remapping, the persisted ids are LIVE ids; restore must yield
959        // the original strings intact.
960        let node = &graph.nodes[0];
961        assert_eq!(
962            GLOBAL_INTERNER
963                .resolve_with(InternedString::from_raw(node.label_idx), |s| s.to_string()),
964            Some(label)
965        );
966        let props = restore_property_map(&node.properties).unwrap();
967        assert_eq!(
968            props.get(key_a.as_str()).and_then(|v| v.as_str()),
969            Some(val.as_str())
970        );
971        assert!(matches!(
972            props.get(key_b.as_str()),
973            Some(crate::core::property::PropertyValue::Int(7))
974        ));
