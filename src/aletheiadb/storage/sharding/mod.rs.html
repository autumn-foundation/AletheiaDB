1//! Sharding support for horizontal scalability.
2//!
3//! This module implements graph sharding for distributing data across multiple machines
4//! when the dataset exceeds single-machine capacity. It uses domain-based partitioning
5//! with edge replication as described in ADR-0014.
6//!
7//! # Architecture
8//!
9//! ```text
10//! ┌─────────────────────────────────────────────────────────────────┐
11//! │                      Shard Coordinator                           │
12//! │   • Query routing         • Transaction coordination             │
13//! │   • Shard discovery       • Rebalancing orchestration           │
14//! └─────────────────────────────────────────────────────────────────┘
15//!               │                    │                    │
16//!               ▼                    ▼                    ▼
17//!      ┌─────────────┐      ┌─────────────┐      ┌─────────────┐
18//!      │   Shard 0   │      │   Shard 1   │      │   Shard 2   │
19//!      │   People    │◄────►│   Places    │◄────►│   Events    │
20//!      └─────────────┘      └─────────────┘      └─────────────┘
21//! ```
22//!
23//! # Key Components
24//!
25//! - [`ShardId`]: Strongly-typed shard identifier
26//! - [`ShardConfig`]: Configuration for shard topology
27//! - [`ShardRouter`]: Routes queries to appropriate shards
28//! - [`ShardCoordinator`]: Coordinates distributed operations
29//! - [`DistributedTransaction`]: Two-phase commit for cross-shard writes
30//! - [`RebalanceManager`]: Handles shard rebalancing
31//!
32//! # Example
33//!
34//! ```rust,no_run
35//! use aletheiadb::storage::sharding::{ShardConfig, ShardCoordinator, ShardDefinition};
36//!
37//! # fn main() {
38//! let config = ShardConfig::new(vec![
39//!     ShardDefinition::new(0, "shard0:9000", vec!["Person", "User"]),
40//!     ShardDefinition::new(1, "shard1:9000", vec!["Place", "Location"]),
41//! ]);
42//!
43//! let coordinator = ShardCoordinator::new(config);
44//! # }
45//! ```
