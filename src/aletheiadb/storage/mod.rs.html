1//! Storage subsystem for graph data.
2//!
3//! This module contains storage engines for both current and historical data:
4//! - Current storage: Optimized for fast current-state queries (hot path)
5//! - Historical storage: Anchor+delta compression for temporal queries
6//! - Cold storage: Disk-based tiered storage for historical versions
7//! - Tiered storage: Transparent hot/warm/cold data access
8//! - Version management: Version chain structures and compression
9//! - WAL: Write-ahead log for durability and crash recovery
10//! - Checkpoint: Full state snapshots via index persistence
11//! - Sharding: Horizontal scaling via domain-based partitioning (ADR-0014)
12
