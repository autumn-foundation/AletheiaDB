**[Query to DB Dependency Cycle]
**Tangle:** The `crate::query` module tests depended on the higher-level facade `crate::db::AletheiaDB` and `crate::api::transaction::WriteOps`, creating a circular dependency (`db -> query -> db`). Furthermore, `QueryBuilder::execute` explicitly required a reference to `crate::AletheiaDB` in the core module.
**Blueprint:** Moved integration-level tests from `src/query/hybrid.rs` and `src/query/semantic_pathfinding.rs` into the `tests/` directory. Abstracted the concrete `AletheiaDB` dependency out of `QueryBuilder` by introducing a `QueryExecutable` trait in `crate::query::builder` which `AletheiaDB` (and its `Arc` wrapper) implements in `src/db/query.rs`. Fixed doc links in `src/query/planner/stats.rs`.
