## 2025-05-21 - [FFI Panic Safety]
**Threat:** The `HnswIndexBuilder` allows user-defined custom distance metrics. These are implemented as Rust closures passed to the `usearch` C++ library via a raw pointer wrapper. If the user-provided closure panics, the panic unwinds across the FFI boundary into C++ stack frames, causing Undefined Behavior (typically an abort, but potentially worse). Additionally, the wrapper blindly dereferences raw pointers from C++ without checking for null, which could lead to segfaults if the underlying library passes nulls (e.g., on allocation failure or bug).
**Defense:** Wrapped the closure execution in `std::panic::catch_unwind` to trap panics before they cross the FFI boundary. Added null checks for the raw pointers passed from C++. In both error cases (panic or null pointer), the metric now returns `f32::INFINITY` to signal "maximum distance" safely to the search algorithm without crashing the process.
