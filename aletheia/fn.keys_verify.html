aletheia keys verify --key-file <PATH> — verify the named key is usable.

Constructs the file key provider and runs its health check (which loads and parses the MEK). This is the scoped v1 of the issue’s encryption verify: it verifies the KEY is loadable/valid, NOT that all encrypted data across all storage layers decrypts (that broader check depends on index encryption, Issue #481, which is not yet on trunk). On failure a safe error category is reported (never key bytes) and the process exits non-zero.
