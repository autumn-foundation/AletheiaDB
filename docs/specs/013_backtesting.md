# 🔭 Vantage: Spec for Backtesting Against Volatile Markets

## 👤 User Story:
As a Trader, I want to backtest against volatile markets, so that I can evaluate the performance of my strategies during high market turbulence.

## ✅ Acceptance Criteria:
- Must handle NaN data without panicking.
- Must output a CSV report.

## 🚫 Out of Scope:
- Real-time execution (Phase 2).
